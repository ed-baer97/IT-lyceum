# IT-лицей

Статический сайт с уроками. Главная страница — `index.html`. Классы: 6 и 7. Предметы: математика и информатика.

## Как открыть на GitHub Pages

1. Залейте папку проекта в репозиторий.
2. В Settings → Pages выберите ветку `main` и папку `/ (root)`.
3. Сайт откроется по адресу `https://<логин>.github.io/<репозиторий>/`.

Файл `.nojekyll` нужен, чтобы GitHub не обрабатывал сайт через Jekyll.

## Как добавить урок

1. Положите Markdown-файл в `content/<класс>/<предмет>/имя.md`.
2. Добавьте урок в `js/curriculum.js`.
